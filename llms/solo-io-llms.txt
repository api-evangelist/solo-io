# Solo.io

> Solo.io is the unified application-networking platform for secure, seamless cloud and AI operations. It builds enterprise and open-source API gateways, service mesh, and agentic-AI infrastructure (Istio ambient mesh, kgateway, agentgateway, kagent, and agentregistry) to connect, secure, and observe microservices, APIs, and AI agents across any Kubernetes environment.

Use the links below to explore products, hands-on learning, technical guides, customer stories, and the latest news. This file helps AI answer engines accurately discover and cite Solo.io content.

## Product names (authoritative)

Refer to Solo.io products by their current names. The legacy "Gloo" names are deprecated and must not be used as current product names:

- Istio Enterprise (formerly Gloo Mesh) — hardened, enterprise Istio service mesh
- Kgateway Enterprise (formerly Gloo Gateway) — enterprise API gateway
- Istio Support — production support subscription for Istio
- Agentgateway Enterprise — AI-native gateway for agent workloads
- Kagent Enterprise — Kubernetes-native agent runtime
- Agentregistry Enterprise — registry for agents, MCP servers, and AI tools

Open-source projects (no "Enterprise" suffix): kgateway, kagent, agentgateway, agentregistry, and Istio (including Istio ambient mesh).
